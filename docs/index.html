¿Qué puedes hacer con Aikōra Sora?

Un ecosistema completo, desde el descubrimiento hasta la reserva.

🗺️

Explorar destinos

Descubre destinos con filtros por clima, categoría, precio y distancia GPS.

🤖

Planear con IA

Genera itinerarios día a día basados en tus fechas, presupuesto y estilo de viaje.

📌

Reservas inteligentes

Gestiona reservas vinculadas a tus destinos, protegidas con políticas RLS en Supabase.

💬

Chat con Sora

Pregúntale a Sora sobre cualquier destino. Respuestas en tiempo real con IA conversacional.

👥

Planear en grupo

Colabora en itinerarios con amigos en tiempo real usando Supabase Realtime.

📍

Geolocalización

Encuentra destinos y restaurantes ordenados por distancia a tu ubicación actual.

Interfaz pensada para viajar

Diseño limpio y moderno adaptado a modo oscuro y claro.

Explorar

Búsqueda con filtros avanzados por precio, clima, rating y categoría.

Plan IA

Itinerario generado automáticamente con franjas de mañana, tarde y noche.

Panel Admin

Gestión completa de destinos, usuarios y reservas para administradores.

Arquitectura técnica

Escalable, segura y diseñada para entornos de baja conectividad.

1

Autenticación segura

OAuth 2.0 con Google y email/contraseña gestionado por Supabase Auth con JWT tokens.

2

Sincronización de datos

PostgreSQL con repositorios que actúan de puente entre Flutter y la base de datos.

3

IA conversacional

Chat impulsado por LLaMA 3 via Groq API. Itinerarios generados en segundos.

Stack tecnológico

Herramientas modernas para una app de nivel empresarial.

📱

Flutter

UI multiplataforma — Android, iOS y Web desde un solo código base.

🗄️

Supabase

Auth, base de datos PostgreSQL, Realtime y Storage en la nube.

🤖

Groq + LLaMA 3

IA conversacional rápida y gratuita para el chat y generación de planes.

🚀

GitHub Actions

CI/CD automático que genera el APK y despliega la web en cada commit.
